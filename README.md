# An toàn thông tin mùa lễ hội

Trang one-page cho Zalopay Security Month 2026. Trang tĩnh, không cần build.

## Cấu trúc
- `index.html`: toàn bộ nội dung và script
- `css/onepage.css`: giao diện
- `assets/img`, `assets/fonts`: hình và font
- `.nojekyll`: để GitHub Pages phục vụ nguyên trạng

## Đưa lên GitHub Pages
1. Giải nén và chép toàn bộ file vào thư mục gốc của repo, ghi đè file cũ.
2. Commit và push lên nhánh `main`.
3. Settings > Pages: Source = Deploy from a branch, Branch = `main`, thư mục `/ (root)`.
